# Neon Dodge

A browser-based arcade game built with vanilla HTML, CSS, JavaScript, and the HTML5 Canvas API. Dodge incoming obstacles, collect power-ups, and beat your high score.

## Play

Open [Neon Dodge on GitHub Pages](https://ajvazi04.github.io/Neon-Dodge/) after Pages is enabled, or open `index.html` in a modern browser.

## Features

- Solo mouse controls and local two-player co-op
- Increasing difficulty, score tracking, and power-ups
- Pause, tutorial, and game-over screens
- High scores saved in browser local storage
- Responsive full-window canvas

## Controls

- **Solo:** Move the mouse to steer.
- **Co-op:** Player 1 uses **WASD**; Player 2 uses the **arrow keys**.
- **Pause:** Press **Esc**.

## Built with

HTML5 · CSS3 · JavaScript (ES6+) · Canvas 2D

The interface and in-game tutorial are in Albanian.
